# Участие в разработке

1. Создайте fork и отдельную ветку.
2. Внесите одно связное изменение.
3. Выполните `python3 Tests/run.py` и `git diff --check`.
4. Для изменений SwiftUI или Network Extension соберите приложение в Xcode.
5. Для изменений интерфейса приложите снимок экрана.
6. Для изменений маршрутизации опишите проверенный сценарий и ограничения проверки.
7. Откройте pull request в `main`.

Укажите проблему, новое поведение и выполненные проверки в описании pull request.
Не добавляйте сертификаты, профили, пароли, токены, журналы с персональными данными
и файлы из каталога `.build`.

Владельцы проекта проверяют каждый внешний pull request перед слиянием.
Успешный CI не заменяет ревью. Проект не использует автоматическое слияние.
